# Monthly SEO check

## Steps
1. Run site_audit on the website; it compares with the last saved audit.
2. Use seo_projects to see the trend if the site is tracked; offer to track it weekly if it is not.
3. Report what improved, what got worse and anything new.
4. Pick this month's three actions.
