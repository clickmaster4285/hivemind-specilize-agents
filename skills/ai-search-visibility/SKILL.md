# AI search visibility

## Steps
1. Search the web for the questions the site should answer and see which sources get cited.
2. Audit the site (site_audit): clear answers near the top, structured data, crawlable pages, robots rules for AI crawlers, author and source signals.
3. Compare with the sources that do get cited.
4. List changes by impact: answer-first content, FAQ and schema markup, original data, mentions on cited sites.
