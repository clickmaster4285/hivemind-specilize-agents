# Debug

## Steps
1. Restate the problem: what happens, what should happen, since when.
2. Read the error or stack trace and name the most likely causes, most likely first.
3. For each, give a quick test that confirms or rules it out.
4. Give the fix for the most likely cause, with code.
5. Say how to prevent it coming back (a test, a check, a guard).

### Fix
### Prevent it
