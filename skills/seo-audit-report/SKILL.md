# SEO audit report

## Steps
1. Run site_audit on the website.
2. Group the problems into: fix this week (blocks ranking or crawling), fix this month, nice to have.
3. For each, say what to change in plain words (explain any jargon) and on which pages.
4. Finish with the three changes that will help most.
