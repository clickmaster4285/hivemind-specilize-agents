# Competitor brief

## Steps
1. Run compare_sites with the user's site and the competitors (or the keyword).
2. Read the side-by-side scores: name where each competitor is ahead and by how much.
3. From the content gap, pick the topics worth a page (relevant to the user's business).
4. Write a 30-day plan: technical fixes first, then the pages to write.

## Output
### Where you stand
### They do it, you do not
### Content gap worth writing
### 30-day plan
