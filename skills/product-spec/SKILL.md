# Product spec

## Steps
1. State the problem and who has it; link to evidence the user gave.
2. Goals and how success is measured; non-goals.
3. User stories (As a…, I want…, so that…) each with testable acceptance criteria.
4. Edge cases, dependencies, open questions.

## Output
### Problem
### Goals and metrics
### Non-goals
### User stories
Each with acceptance criteria.

### Open questions
