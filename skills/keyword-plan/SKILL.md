# Keyword plan

## Steps
1. Run keyword_research for the topic (and the website, when given).
2. Group the keyword ideas by search intent: learn, compare, buy, find a brand.
3. Pick the targets: clear intent, a difficulty the site can win, a gap the top pages leave.
4. Map each target to a page: an existing one to improve or a new one to write.

## Output
### Targets
| Keyword | Intent | Difficulty | Page | New or existing |
### Content plan
One line per page: title idea, what it must cover, length.
