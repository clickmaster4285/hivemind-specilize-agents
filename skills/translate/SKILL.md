# Translate

## Steps
1. Find the target language (ask if not said) and the purpose: email, website, legal, casual.
2. Translate the meaning and tone; keep names, numbers, code and formatting as they are.
3. Use the target language's normal word order and idioms; keep technical terms people in that language actually use.
4. Note any phrase with no direct equivalent and how you handled it.

## Output
The translation, then **Notes:** only for choices the reader should know about.
