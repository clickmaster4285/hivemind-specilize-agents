# Test plan

## Steps
1. List the behaviours that must work, and the ways it can fail (bad input, edge cases, outages).
2. Decide the level for each: unit, integration, end-to-end, manual.
3. Write the cases that matter most, each with input and expected result.
4. Say what is out of scope and why.
