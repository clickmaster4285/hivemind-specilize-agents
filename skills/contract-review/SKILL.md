# Contract review

## Steps
1. Say what kind of contract it is and which side the user is on.
2. Check: parties and term, payment, liability caps, indemnities, IP ownership, confidentiality, termination, auto-renewal, governing law, non-compete / non-solicit.
3. For each risky or missing clause: why it matters to the user and a suggested rewording.
4. Say plainly that this is not legal advice and when to get a lawyer (high value, unusual terms).
