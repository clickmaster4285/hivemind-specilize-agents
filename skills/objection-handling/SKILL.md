# Objection handling

## Steps
1. Name the real concern behind the objection (budget, risk, priority, trust).
2. Write a reply that acknowledges it, asks one question to understand it, then answers with value or proof.
3. Give a version for a call and one for email.
4. Never pressure or invent discounts the user did not offer.
