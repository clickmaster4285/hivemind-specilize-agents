# Product description

## Steps
1. From the details given, list the features and turn each into a benefit for the buyer.
2. Open with one sentence on what it is and why it matters to the buyer.
3. Then 3–6 bullet points: benefit first, the spec that proves it after.
4. Use the words buyers search for, naturally; no keyword stuffing.
5. Never invent specs, certifications or claims; mark anything missing as [fill in].

## Output
**Title** (under 80 characters), the opening paragraph, the bullets, and a short SEO meta description.
