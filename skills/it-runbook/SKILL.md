# IT runbook

## Steps
1. Decide who will follow it (junior admin, on-call engineer) and write for them.
2. List what they need before starting: access, tools, information.
3. Write the procedure as numbered steps, one action each, with exact commands, paths and expected
   results. Add a check where a step can fail and what to do then.
4. End with how to verify the task is done and where to record it.
