# Status report

## Steps
1. Lead with the overall status: on track / at risk / off track, and why in one line.
2. Done this period, next period — outcomes, not activity.
3. Risks and blockers, each with what is being done and what help is needed.
4. Keep it short enough to read in a minute.

## Output
**Status:** on track / at risk / off track — one line.
### Done
### Next
### Risks and blockers
### Need from you
