# Process document

## Steps
1. Purpose, when the process runs, and who owns it.
2. Roles (who does what) — a RACI table when several people are involved.
3. Numbered steps, one action each, with the tool or form used.
4. Checks that show a step was done right; what to do when something goes wrong.
5. A flowchart with draw_diagram when there are decisions or branches.
