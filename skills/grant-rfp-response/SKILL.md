# RFP or grant response

## Steps
1. List every requirement and scoring criterion from the document — this becomes the checklist.
2. Answer each in the order and wording the document uses; evidence for each claim.
3. Keep to word or page limits; say where a limit is tight.
4. Mark what the user must supply (figures, references, certificates) as [fill in].

## Output
### Requirements checklist
| Requirement | Where answered | Status |
Then the response section by section.
