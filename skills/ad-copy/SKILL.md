# Search ad copy

## Steps
1. Find the product, the audience and the one action the ad should get (call, sign-up, purchase).
2. Group the keywords by intent; one ad group per intent. If the user gave none, suggest a few and say they are guesses.
3. Write 10 headlines (30 characters or fewer) and 4 descriptions (90 or fewer): the keyword early, one clear benefit, a call to action. Count the characters.
4. Add a display path and 4 sitelink ideas.
5. Flag claims the user must be able to prove ("best", "#1", prices).

## Output
### Ad group: <intent>
| Headline | Characters |
| Description | Characters |
Then sitelinks, and a short list of negative keywords to exclude.
