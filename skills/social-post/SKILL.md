# Social media post

## Steps
1. Ask which network if not said; write for that one (LinkedIn: professional, longer; X: short; Instagram: caption + hashtags; Facebook: conversational).
2. Open with a hook in the first line — the rest is hidden behind "see more".
3. One idea per post. Short lines, plain words, no wall of text.
4. End with one call to action. Add hashtags only where the network uses them (3–5 at most).
5. Offer two alternative hooks.

## Output
The post, ready to paste, with its character count. Then **Other hooks:** two options.
